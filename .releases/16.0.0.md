**Breaking Changes**

* Changed the `PortfolioSchema` definitions.
* Changed the `PositionSchema` definitions.

**New Features**

* Added the `defaults.taxable` attribute to some `PortfolioSchema` definitions.
* Added the optional `instrument.option.underlying` attribute to the complete and client `PositionSchema` definitions.
* Added `PositionContainer.replaceTree` to rebuild an existing aggregation tree, with support for preserving its top-level group bindings.
